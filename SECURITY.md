# Security policy

Keel handles secrets and credentials (redaction, subprocess environments, SSH keys, Docker and Proxmox API access), so security reports are very welcome.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private security advisories:

1. Go to https://github.com/springledev/keel/security/advisories/new
2. Describe the problem, the package involved, and steps to reproduce it.

You will get a reply as soon as the maintainer can look at it. If the report is confirmed, the fix will be prepared privately, released as a new tag, and credited to you if you want credit.

## Supported versions

Only the latest tag is supported. Fixes are released as a new tag rather than backported to older ones, so please update to the latest tag.
